## Decision classes

- **Adopt:** approved bounded dependency or platform API after its phase gate.
- **Adapt:** reuse a narrow pattern or protocol behind ONE BOX contracts.
- **Evaluate:** benchmark locally before deciding.
- **Learn only:** study UX or architecture without code reuse.
- **Reject:** conflicts with source authority, security, maintenance, product scope, or license.
- **Needs license review:** no code-level use until the license question is resolved.

No catalog entry authorizes a dependency change. The phase plan names the required benchmark, security oracle, schema review, or owner gate before adoption.

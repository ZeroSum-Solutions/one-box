## Non-substitution rule

Contract/cost, security, human-decision, apply-eligibility, quality, exact-Grok,
exact-Fable, independent security verification, and repository-owner authorization
are different lanes. No favorable result in one lane supplies another lane's verdict
or authority.

## Explicit exclusions

This packet does not add or enable a provider, model, credential, dependency,
persistence layer, background process, live skill/tool, browser, connector,
collaboration, UI surface, teammate-driven Page IR mutation, deployment, release, or
product runtime integration. Existing pinned generation routes remain unchanged.

Implementation can begin only after the repository owner fills every placeholder,
assigns the required separated named humans, and accepts the exact scoped proposal
in the authority manifest. Until then, the executable fixtures are planning evidence,
not product behavior or release gates.

## Program sequence

1. P1: closed lifecycle authority and receipts.
2. P2: Canvas candidate and approval automation.
3. P3: version-bound private client review.
4. P4: agency qualification and evidence-bound SEO.
5. P5: release orchestrator and conformance provider.
6. P6: separately selected production provider.
7. P7: appointment release integration.
8. P8: end-to-end qualification and controlled rollout.

Canvas never writes live production files. The release owner approves one exact qualified bundle; the deployment adapter can execute that decision but cannot create it.

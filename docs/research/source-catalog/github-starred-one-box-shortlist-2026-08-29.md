# GitHub starred shortlist for ONE BOX

Snapshot date: 2026-08-29

This is the source-checked shortlist produced from all 133 starred repositories. It is the only planning disposition and phase-label authority for starred repositories in this catalog. The 107-item relevance report and JSON preserve census and first-pass traceability; they do not add candidates or override this file. Every entry below has a bounded research or adoption disposition. A phase label does not authorize that phase or code use: the accepted parent contract, adoption-ledger entry, ticket, evaluation, and human authorization still control retained work. None is a replacement for the ONE BOX repository or its production authority chain.

## Selection rule

The first pass found 107 relevant repositories. A repository entered this 18-item shortlist only when current primary README, license, and targeted source evidence identified a specific pattern that could change a named ONE BOX architecture, protocol, gate, or dependency choice; the pattern was not better covered by another candidate; its phase fit preserved Page IR and the existing authority chain; its maintenance and operational burden fit the proposed use; and its license either supported that use or failed closed as `Needs license review`. Metadata-only matches, duplicate patterns, weaker candidates, alternate authorities, disproportionate runtimes, and general inspiration stayed outside the 18.

Treat it as visual inspiration only after legal review.

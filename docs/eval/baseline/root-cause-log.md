# Baseline root-cause decision log

## Confirmed before the new run

- The legacy local-library and Crawl4AI wrapper paths were machine-specific. This was
  a setup defect, not a visual-quality cause.
- The existing frozen template and gates produce a meaningful quality floor even in a
  no-reference arm.
- The prior advisory experiment did not prove Refero was a pipeline multiplier.
- Competitor research and design-reference research already use separate pipeline
  artifacts, which reduces direct visual contamination.

## Inferred candidates

The next comparison will test these candidates rather than assuming them:

1. research queries too broad for local trade categories;
2. lossy conversion of Refero records into a small reference lock;
3. design-contract synthesis weakening distinctive reference traits;
4. template structure dominating the design evidence;
5. imagery generation creating generic collages;
6. tokens too narrow to encode responsive and component-state decisions;
7. visual evaluation too weak or inconsistent to reject mediocre output.

## Unresolved

No candidate is confirmed as the root cause. Path A and Path B have not run under the
new identical-input contract because Refero OAuth and the OpenRouter vault lane are not
currently available. The smallest safe next experiment is the frozen fiber fixture with
one output per path, identical downstream builder configuration, and blind scoring.

## Revised pipeline decision

Deferred. The brief prohibits a pipeline revision until the controlled run identifies
which stage introduces the quality loss.

# Risk-exception registry

This directory is the proposed registry for the narrow exception class allowed by
the program evaluation strategy. It currently contains no active exception and
grants no authority.

Authentication/authorization, tenant isolation, untrusted browser or file input,
secrets/privacy, loss-risk migrations, release/rollback, appointment authority,
and release-candidate verification are non-waivable. Any eligible future entry
must identify the risk owner, scope, evidence, compensating control, escalation,
and an expiry no more than fourteen days later.
